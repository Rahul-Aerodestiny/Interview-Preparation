📘 Basic Software Interview Questions

Core programming and computer science questions for interviews.

1. What is the difference between C and C++?

Ans: C is procedural, C++ supports object-oriented programming.

2. Explain OOPs principles.

Ans: Encapsulation, Abstraction, Inheritance, and Polymorphism.

3. What is a primary key in DBMS?

Ans: A unique identifier for a record in a table.

4. What is normalization in DBMS?

Ans: Process of structuring data to reduce redundancy and improve integrity.

5. What is a deadlock in Operating Systems?

Ans: A state when processes wait indefinitely for resources held by each other.

6. Explain difference between process and thread.

Ans: Process is an independent program, thread is a lightweight unit of execution within a process.

7. What is recursion?

Ans: Function calling itself directly or indirectly to solve subproblems.

8. What is the difference between stack and queue?

Ans: Stack = LIFO, Queue = FIFO.

9. What is Big O notation?

Ans: It represents time/space complexity of an algorithm in worst-case terms.

10. Explain differences between SQL and NoSQL databases.

Ans: SQL = relational, structured, strict schema. NoSQL = non-relational, flexible schema, scalable.

11. What is polymorphism in OOP?

Ans: Ability of a function or object to take multiple forms (compile-time and runtime).

12. Explain REST API.

Ans: Representational State Transfer, uses HTTP methods (GET, POST, PUT, DELETE) for communication.

13. What is Git and why is it used?

Ans: Git is a version control system to track changes and collaborate on code.

14. What is difference between compilation and interpretation?

Ans: Compilation translates code to machine language once, interpretation executes line by line.

15. What are microservices?

Ans: An architecture style where applications are built as independent, small services communicating via APIs.
